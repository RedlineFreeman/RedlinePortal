# 🚀 Полное руководство по запуску SysAdmin Pro на личном VPS и офлайн на ПК

Привет! Это приложение создано специально так, чтобы его можно было **в 1 клик запустить на любом собственном сервере (VPS)**, в локальной сети компании или просто на домашнем компьютере без интернета.

---

## 🧭 Варианты использования:

| Вариант | Кому подходит | Требования к ресурсам | Срок развертывания |
|---|---|---|---|
| **1. Docker Compose на VPS** (Рекомендуется) | Для постоянного личного сайта/лаборатории | 1 vCPU, 1 GB RAM, 10 GB SSD | 2-3 минуты |
| **2. Чистый Nginx на VPS** | Для ультра-бюджетных VPS (за 100-150 руб) | 1 vCPU, 512 MB RAM | 3 минуты |
| **3. Локально через Node.js** | Для разработки и изучения кода | Компьютер с Node.js 20+ | 1 минута |
| **4. Автономный Офлайн HTML** | Без сервера, без Node.js, без интернета | Любой веб-браузер | 1 секунда (двойной клик) |

## 🛠️ Пошаговый запуск на VPS (Ubuntu / Debian / CentOS / Rocky)

### Шаг 1: Аренда VPS сервера
Подойдет любой хостинг:
- **Россия / СНГ**: Timeweb Cloud, Selectel, Beget, Aeza, FirstVDS.
- **Международные**: Hetzner, DigitalOcean, OVH.
- Выберите ОС: **Ubuntu 22.04 LTS** или **Ubuntu 24.04 LTS**.
- Минимальный тариф: 1 ядро, 1-2 ГБ оперативной памяти.

### Шаг 2: Подключение по SSH
```bash
ssh root@<IP_АДРЕС_ВАШЕГО_СЕРВЕРА>
```

### Шаг 3: Размещение файлов
В веб-приложении во вкладке **"Скачать / VPS & Офлайн"** нажмите **"Скачать весь проект (ZIP)"**.
Скопируйте файлы на сервер (через SCP, FileZilla, WinSCP или Git):
```bash
mkdir -p /opt/sysadmin-pro
cd /opt/sysadmin-pro
# Распакуйте сюда содержимое архива
```

### Шаг 4: Запуск в 1 команду
```bash
chmod +x deploy.sh
sudo ./deploy.sh
```
Скрипт автоматически:
1. Проверит и установит официальный Docker Engine и Docker Compose.
2. Соберет оптимизированный Docker-образ приложения.
3. Откроет порты 80 и 443 в фаерволе UFW.
4. Запустит сервис с автоперезапуском при ребуте сервера (`restart: unless-stopped`).

После этого откройте в браузере: `http://<IP_СЕРВЕРА>`

## 🔒 Настройка домена и бесплатного SSL-сертификата (HTTPS)

Если у вас есть домен (например `sysadmin.ru` или субдомен `lab.mydomain.ru`):
1. В панели управления DNS вашего регистратора направьте **A-запись** на IP-адрес вашего VPS.
2. На сервере выполните:
```bash
sudo apt update && sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d lab.mydomain.ru
```
Certbot автоматически получит сертификат от Let's Encrypt и настроит автоматическое продление!

## 🛡️ Базовая безопасность VPS (Чеклист сисадмина)

После запуска не забудьте настроить защиту:
1. **Вход только по SSH ключам**:
   ```bash
   ssh-copy-id root@<IP_СЕРВЕРА>
   # В файле /etc/ssh/sshd_config: PasswordAuthentication no
   systemctl restart sshd
   ```
2. **Включение фаервола UFW**:
   ```bash
   ufw default deny incoming
   ufw default allow outgoing
   ufw allow 22/tcp
   ufw allow 80/tcp
   ufw allow 443/tcp
   ufw enable
   ```
3. **Установка Fail2ban против брутфорса**:
   ```bash
   apt install -y fail2ban
   systemctl enable --now fail2ban
   ```

## 💻 Локальный запуск на своем компьютере

```bash
# Клонируйте или распакуйте архив
cd /path/to/project

# Установите зависимости
npm install

# Запустите сервер разработки
npm run dev
# Портал откроется на http://localhost:3000

# Либо соберите статическую версию:
npm run build
# Готовая статика будет в папке /dist, которую можно отдать любым веб-сервером
```
